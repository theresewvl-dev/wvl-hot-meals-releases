# WVL Hot Meals Operations — Android app

Current version: **1.0.6** (build 7)

**Download:** [wvl-hot-meals-1.0.6.apk](https://github.com/theresewvl-dev/wvl-hot-meals-releases/raw/main/wvl-hot-meals-1.0.6.apk)

Works on any Android phone or tablet with Android 7.0 or newer.

## Installing

1. Open the download link above on the device.
2. Open the downloaded file. The first time, Android asks to allow
   "Install unknown apps" for the app that opened it: allow it.
3. If Play Protect warns about an unrecognised app, choose **Install anyway**.

Installed apps show "Version x is available — Download" on the dashboard
when a newer version is published here, and updating keeps everything on
the device.
